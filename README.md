**Descrição:**
Site pessoal de currículo e portfólio desenvolvido exclusivamente com **HTML5 e CSS3**, sem JavaScript e sem frameworks.

## **Como visualizar**
Abra o ficheiro `index.html` num navegador. Para ver todos os elementos multimédia, coloque as suas imagens, áudio e vídeo nas respetivas pastas dentro de `assets/`.

 Páginas
-**Home:** apresentação, competências, imagem, vídeo e áudio.
- **Sobre/Currículo:** formação, experiências, lista, tabela e certificados.
- **Portfólio:** projetos apresentados em cartões com CSS Grid.
- **Hobbies:** interesses organizados com Flexbox e áudio.
- **Contacto:** formulário completo com validação nativa HTML5.

## Principais tecnologias e recursos utilizados
- `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>` e `<footer>`: estrutura semântica.
- `<figure>` e `<figcaption>`: imagens com legenda.
- `<img>` com `alt`: acessibilidade e descrição das imagens.
- `<video>` e `<audio>` com `<source>`: elementos multimédia nativos.
- `<form>`, `<fieldset>`, `<legend>` e `<label>`: formulário acessível e organizado.
- `required`, `minlength`, `maxlength`, `pattern`, `min` e `max`: validação nativa sem JavaScript.
- **Flexbox:** organização do menu e dos hobbies.
- **CSS Grid:** organização dos cartões do portfólio.
- `:root`: variáveis CSS para cores e espaçamentos.
- `:hover`, `:focus`, `:first-child`, `:last-child`, `:nth-child`: pseudo-classes.
- `::before`: pseudo-elemento decorativo.
- `transition` e `@keyframes`: efeitos e animação.
- `position: sticky`: cabeçalho visível durante a rolagem.
- **Media queries:** adaptação para tablet e desktop seguindo uma abordagem mobile-first.
